Campaign Forge — installable app

Put every file in this folder on a free static host (GitHub Pages, Netlify Drop or
Cloudflare Pages), then open the link:

- Phone (iPhone): Safari > Share > Add to Home Screen.
- Phone (Android): Chrome > menu > Install app (or Add to Home Screen).
- Computer: Chrome or Edge > the install icon in the address bar.

Once installed it opens full screen with its own icon and keeps working offline.
Your tables are saved in that device's browser; use Scenes > Save to file to back up
or move a game between devices.
